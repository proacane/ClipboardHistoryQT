# ADR-0001：新项目技术基线

- 状态：Qt 6.11.1 MinGW Debug / RelWithDebInfo 本轮 11/11 CTest 模块通过；功能自动验收通过，完整发布门禁未通过。CI、正式 Ref-01、应用许可证尚未确定
- 日期：2026-10-10；更新：2026-10-12
- 适用范围：Clipboard History 新版
- 关联规范：[开发与测试规范](../development-spec.md)

## 背景

建立本 ADR 时选择新工程重做；旧版保留为行为参考和只读数据导入来源。当前已有应用实现和 Git 元数据，工作区仍含未提交改动，不能以初建时状态描述当前交付。

## 已确认的方向

| 决策 | 当前基线 | 说明 |
|---|---|---|
| 重构方式 | 新工程骨架，按阶段重做 | 保留经过验证的产品行为和旧数据导入路径；不继承旧类/线程耦合。 |
| Windows 最低版本 | Windows 10 1809+ | 用户已确认；后续 Qt 升级须遵守 Qt 对 Win10 的支持窗口。 |
| UI | Qt Quick + QML | 视图负责展示与交互；性能敏感逻辑留在 C++。 |
| 核心语言与工具链 | C++17；Qt 6.11.1 MinGW 64-bit / GCC 13.1.0 | CMake 与实际编译参数均为 C++17；使用与 Qt kit 匹配的 MinGW。 |
| 大列表 | C++ QAbstractListModel + QML ListView | 分页/增量加载，不将完整历史复制到 QML。 |
| 剪贴板线程边界 | Qt GUI 线程快速读取并复制 MIME 快照；后台线程做哈希、图片处理、数据库持久化 | 不把 QClipboard 直接移到任意 worker。 |
| 数据库 | SQLite schema v5，本地单写者连接 | 连接固定归属存储工作线程；schema 带版本迁移，SQL 参数化。 |
| Windows 全局热键 | Win32 RegisterHotKey | 已集成；键盘录制期间注销原组合，成功后重注册，取消时恢复。QHotkey 未引入。 |
| 图片 | 独立内容文件 + 哈希去重 + 原子写 | DB 引用提交前不清理原文件；写失败不产生确认记录丢失。 |
| 路径 | 可执行文件旁的 data/ 为默认数据根；设置中可改为可写空目录 | config.ini、SQLite、图片和日志统一位于当前数据根；ClipboardHistory.ini 在可执行文件旁保存自定义路径指针。不可写目录明确失败，不回退到系统用户目录。 |
| 隐私 | 默认本地，不加入云同步和遥测 | 日志不记录剪贴板正文；持续监听并提供历史清理；敏感格式策略需阶段0定稿。 |
| 迁移 | 只读旧版数据，导入新版目录 | 可重复、可校验；绝不修改旧数据库和图片。 |
| UI / 核心接口 | QML 通过类型化 C++ model/service 有限 API 通信 | QML 不直接跑 SQL、不读写大文件。 |

风险：程序目录不可写（如 Program Files）时 Windows 会提示错误并退出，不回退至系统用户目录；便携程序应放在可写目录。设置仅保存待切换目标，下次启动在数据库服务打开前复制并切换，失败回滚并继续使用源目录；旧目录保留。若未来支持运行期迁移，必须停止采集、排空队列并关闭数据库/日志连接。

## 依赖现状

2026-10-14 发布更新：用户确认本项目原创代码使用 MIT，见根目录 LICENSE 与 THIRD_PARTY_NOTICES.md。自动保留、数量上限、登录自启动及本地 Git 提交已实现；下文部分待定项为早期决策历史，最新状态以 README 与 development-spec.md 为准。

Windows 当前使用系统 RegisterHotKey、原生托盘和 Qt QLocalServer，没有 QHotkey 依赖，也没有 IHotkeyBackend 接口。旧版 QHotkey 可作为未来 Linux 方案参考；若决定引入，再固定来源、修订号和许可证。Linux 后端尚未实现。

AppSettings 和 PrivacyLogger 已有独立模块测试，但 main/QML 尚未使用这两个模块。当前 UI 外观设置直接使用 QtCore.Settings；不能把模块 schema/隐私 canary 测试当作应用集成证据。

## 下一步

本轮 Debug 与 RelWithDebInfo 整批 11/11 CTest 已通过，原 DLL 路径问题已修。默认 offscreen QML 验收使用真实数据核心和平台替身，不操作真实剪贴板/热键/托盘；平台子进程覆盖直接退出、托盘退出命令与实例锁释放。

当前主构建完成三轮合成基准；用户手测无明显问题，但连续 60 秒真实 GPU 滚动、GUI 冷/热启动、真实采集回调和桌面焦点/托盘/DPI证据仍不完整。Res.qtd 为 106.94565 秒、4,255 条 RenderLoop，4 个动画事件不是总渲染帧数。500k 隔离 QML 的 30 分钟运行校验已完成，0 Qt/QML warning，最终计数正确，末尾 RSS 82.72 MiB；后半程仍有轻微增长，不据此签署无限期无泄漏。实际列表采用 cacheBuffer=0 避免筛选刷新时屏外条目取消警告，真实 GPU 滚动影响待量化。

自动保留、全库孤儿扫描、自启动、Explorer 重启托盘恢复、Linux 后端、正式安装包与 CI 尚未实现；Ref-01 与应用许可证未冻结，Git 工作区尚无初始提交。功能自动验收通过不能等同发布门禁通过。详见 [本轮验收记录](../handoffs/ACCEPTANCE-2026-10-12.md)。
