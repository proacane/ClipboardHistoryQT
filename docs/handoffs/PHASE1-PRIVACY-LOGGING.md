- 目标：提供轻量异步日志接口，只记录事件、耗时、计数和错误码；避免剪贴板正文、图像数据和完整私人路径进入普通日志。
- 已完成：新增 PrivacyLogger 头文件和实现；记录只接受数值代码与数值；使用 AppPaths::dataDirectory()/logs/events.log（便携/自定义数据根）；写线程通过有界队列异步接收记录，文件按 1 MiB 滚动并保留两个归档文件。

## 契约和决策

- 对外接口 / 数据 schema / 配置变化：ClipboardHistory::Core::PrivacyLogger 提供 recordEvent(quint32)、recordDuration(quint32, qint64)、recordCount(quint32, qint64)、recordError(qint32)。日志行字段仅为 UTC 时间、记录类型和数值码/数值；不接受自由文本。
- 兼容影响：无外部依赖；Qt 6/C++17；代码已加入可执行目标，尚未构建验证。队列上限 1024，争用或满载时丢弃新记录并累计 droppedRecords()。后端故障码可由 backendError() 查询；不递归记录后端错误。
- 已同步给哪些依赖模块：尚未集成；交给主任务确定稳定事件码表和调用点。

## 风险、已知问题与复现

- 风险/限制：用户数据目录不可写时，后台线程会退出并将错误置于 backendError()；调用者应在受控时机检查错误。正常调用不等待文件 I/O；析构会等待后台线程排空队列，集成方避免在高频 UI 路径销毁 logger。
- 已知问题：尚未编译或测试；事件和错误码需由集成者定义稳定含义。文件滚动通过文件系统重命名实现，目标目录权限/占用可能使旋转失败。
- 复现步骤：验证阶段可使用独立临时应用数据目录；以合成记录触发 1 MiB 滚动，并注入不可写目录检查错误状态。不得使用真实剪贴板数据。
